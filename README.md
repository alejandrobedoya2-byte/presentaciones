# Presentaciones

Borradores de presentaciones de trabajo, publicados para verlos desde cualquier computadora. No es un sitio de ninguna empresa.

- Cada carpeta es una presentación, con fecha y tema: `aaaa-mm-tema/`.
- Dentro, una carpeta por prueba o versión, y una página que las lista.
- La portada (`index.html`) se rehace sola con las presentaciones que hay.

Las páginas no se indexan en buscadores.
